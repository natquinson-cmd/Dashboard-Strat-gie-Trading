Logique du JOIN
WMMPU001 (postes EKPO) est la table pilote : elle contient le fournisseur (SUPPLIER), les montants (NETAMOUNT) et quantités (ORDERQUANTITY) de référence au niveau poste. WMMPU002 (imputations EKKN) est jointé en enrichissement pour apporter GL_ACCOUNT, WBS_ELEMT et FUND.

Important : Les montants/quantités de WMMPU002 sont ventilés par ligne d'imputation (split accounting) et ne doivent pas être utilisés comme KPIs de référence.

Transformation FISCPER — Dans la branche BW4, dériver 0FISCPER depuis PURCHASEORDERDATE (YYYYMMDD → YYYYPPP) via la table de dérivation de période fiscale dans la transformation BW.
Règle de dédoublonnage — Définir une date de cutover (ex : 01.01.2026). A750PURC1 → FISCPER ≤ 2025012 | WMMPU002 → PURCHASEORDERDATE ≥ 01.01.2026.
Point d'attention EKKN — Une commande d'achat peut avoir plusieurs lignes d'imputation (split accounting). Le JOIN avec WMMPU001 est un LEFT JOIN : une ligne poste peut correspondre à N lignes d'imputation. Les KPIs (montant, quantité) dans WMMPU002 sont déjà au niveau imputation (avec MULTIPLEACCTASSGMTDISTRPERCENT).
